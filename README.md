## Tasks Completed

### Task 1: Mobile App Signup Flow ✅
**Description:** Design a user-friendly mobile app signup flow that is short, personalized, useful, error-free, and secure.

**Key Features:**
- Clean and intuitive signup process
- Minimal form fields to reduce friction
- Clear error handling and validation
- Secure authentication flow

**Technologies Used:** Figma, HTML, CSS, JavaScript

---

### Task 2: Email Template ✅
**Description:** Create a professional and engaging email template that is visually appealing, easy to use, and responsive across all devices.

**Key Features:**
- Responsive design for all devices
- Professional visual layout
- Easy customization options
- Cross-platform compatibility

**Technologies Used:** HTML, CSS, Responsive Design

---

### Task 3: Restaurant Menu ✅
**Description:** Design an interactive restaurant menu UI/UX that is visually appealing, easy to navigate, and properly categorized.

**Key Features:**
- Interactive menu with categories
- Search functionality
- Add to cart system
- Mobile-responsive design
- Rating and reviews system

**Technologies Used:** HTML, CSS, JavaScript

**Live Demo:** [View Restaurant Menu](./Task-3-Restaurant-Menu/)
